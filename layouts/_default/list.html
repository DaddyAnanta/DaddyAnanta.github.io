Saya adalah seorang Data Analyst dan praktisi SEO Specialist yang fokus pada eksekusi berbasis data. Saya membantu bisnis memahami performa digital mereka melalui angka yang akurat dan struktur website yang sehat.

Fokus utama saya adalah mengubah data mentah menjadi rekomendasi yang praktis. Saya mengerjakannya dengan:

  • Melakukan audit teknis menggunakan Screaming Frog untuk mendeteksi isu crawling dan indexing pada website.
  • Mengolah data secara efisien menggunakan Spreadsheet dan SQL untuk kebutuhan analisis harian dan pelaporan.
  • Menyusun strategi konten berbasis riset volume pencarian via Google Keyword Planner dan menerjemahkannya ke dalam Content Brief yang terstruktur.

Dengan latar belakang psikologi, saya memiliki pendekatan unik dalam menganalisis User Intent—memahami mengapa user mencari kata kunci tertentu, lalu mengoptimalkannya agar relevan dengan target audiens.

Keahlian Utama: Data Analysis (Excel/Sheets, SQL, Python), SEO Tools (Screaming Frog, GKP, GSC), Web Analytics (GA4), Data Visualization (Looker Studio).
